# Security

This is experimental remote desktop software. Host access is limited to the configured owner by default; guest access is opt-in. The web panel listens on loopback and requires a local PIN. The session token is stored outside the repository in a root-only file.

Never include credentials, session.env, desktop settings or full account responses in bug reports. Report a vulnerability privately using GitHub's security reporting feature when the repository owner enables it; otherwise contact the maintainer through a private channel. Do not post exploitable details in a public issue before coordination.
